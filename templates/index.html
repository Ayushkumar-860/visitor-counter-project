Architecture & Technology Stack

🐍

Flask (Python 3.10)

Lightweight WSGI web framework. Handles HTTP requests, renders Jinja2 templates, and exposes REST endpoints.

⚡

Redis 7

In-memory data store used as a persistent, atomic visitor counter. INCR is race-condition-free across multiple workers.

🐳

Docker + Compose

Containerises the app and Redis. Multi-stage build minimises image size. Named volume persists counter across restarts.

☸️

Kubernetes (Minikube)

Orchestrates Flask replicas, provides self-healing, and scales pods with the Horizontal Pod Autoscaler under load.

📈

HPA & Metrics Server

Monitors CPU usage. Scales Flask pods from 2 → 5 replicas when CPU exceeds 50%. Scales back down during idle.

🔀

Failover Gateway

Local reverse proxy simulates hybrid-cloud failover between two Minikube clusters (private-cluster + public-cluster).
